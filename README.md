# rsschool-cv

## CV. HTML, CSS & Git Basics

This repository contains my CV project for the RS School course.

### Deployed CV
You can view the deployed version of my CV here:  
👉 [https://KarynaBertash.github.io/rsschool-cv/](https://KarynaBertash.github.io/rsschool-cv/)

### Project Structure
- `index.html` — CV page with semantic HTML structure.
- `style.css` — Stylesheet for layout and design.
- `README.md` — Project description and deployment link.

### Workflow
- Main branch: contains only `README.md`.
- `gh-pages` branch: used for deployment.
- `rsschool-cv-html` branch: contains CV implementation (`index.html`, `style.css`).

### Commit Guidelines
Each commit message starts with one of the following prefixes:
- `init:` — initial setup
- `feat:` — new feature
- `fix:` — bug fix
- `refactor:` — code refactoring
- `docs:` — documentation update
